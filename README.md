# 스키마 (Schema) — 개인 맞춤 영어독해 학습 앱

> 개개인의 수준에 따라 부족한 부분만 반복 학습하는 맞춤 학습 앱 (2026-2 영어독해연습 1조)

## 바로 사용하기 (인터넷 주소)
- **전체 기능 버전 (마이크 · 발음 점수 · 알림 포함):** https://happymeal9054.github.io/schema-english/ — Chrome/Edge 권장
- **Claude AI 연결 버전 (AI 첨삭 · AI 지문 생성):** https://claude.ai/artifact/Gt1csNKVxFsKazANWHPvby — claude.ai 로그인 필요, 마이크 기능 없음

## 실행 방법 (내 컴퓨터에서)
- **가장 간단한 방법:** `index.html`을 **Chrome 또는 Edge**로 열기 (더블클릭).
- 마이크(발음 점수·녹음)를 쓰려면 로컬 서버로 여는 것이 가장 안정적입니다:
  ```
  python -m http.server 8765
  ```
  그다음 브라우저에서 http://localhost:8765 접속.
- 설치, 회원가입, API 키가 필요 없고 무료로 동작합니다. 학습 기록은 브라우저(localStorage)에 저장됩니다.

## 활동지 기능 → 앱 구현 대응표
| 영역 | 활동지 아이디어 | 앱에서의 구현 |
|---|---|---|
| Vocabulary | 회차별 단어 시험 | 지문 = 회차(1~3회차), 3가지 유형 10문제, 회차별 최고 점수 기록 |
| | 틀린 문제 반복 숙달 | AI 메모리: 3회 연속 정답 시 졸업, 간격 반복(바로→1일→3일) |
| | 시험 알림 서비스 | 매일 정한 시간 브라우저 알림 + 캘린더(.ics) 매일 일정 등록 |
| Listening | 틀린 단어 활용 예문 | 틀린 단어가 들어간 문장을 모든 지문에서 찾아 들려줌 |
| | 예문 읽어주기 | 문장별·전체 듣기, 반복 재생, 속도 조절, 블라인드 듣기, 받아쓰기 |
| Speaking | 예문 읽으면 AI가 점수 책정 | 음성 인식으로 단어별 비교 → 발음 점수, 틀린 단어 빨간 표시 |
| | 본인이 녹음한 것 다시 듣기 | 원어민 음성과 내 녹음을 번갈아 듣기 |
| | 예문 활용 AI 대화 | 지문 주제 질문 → 답변 피드백(핵심어·연결어·어법) → 다음 질문 |
| Grammar | 틀린 문법 AI 문제 생성 | 지문 속 문법 자동 탐지(5형식·일치·시제·태·준동사 등), 오답 해설 |
| | 지속적으로 틀리는 문법 자동 생성 | 문법별 정답률 분석 → 약점 문법 맞춤 문제 자동 출제 |
| Reading | 사용자 맞춤 지문 생성 | 내 오답 단어·약점 문법이 들어간 문장으로 맞춤 연습 지문 구성 |
| | 원하는 내용의 지문 생성 | 주제·수준 입력 → 생성형 AI 프롬프트 생성 → 받은 지문을 앱에 넣어 학습 |
| | 문장별 해석·구문 분석 | 해석, 구조 분석, 글의 흐름, 주제·내용 일치·추론 문제 |
| My Learning | 학습 결과 및 오답 관리 | 영역별·문법별 정답률, 오답 노트(단어·문법·독해), AI 학습 추천 |

## 파일 구성
- `index.html` — 화면 뼈대 · `style.css` — 디자인(라이트/다크 모드, 모바일 하단 탭)
- `passages.js` — 앱용으로 새로 작성한 오리지널 지문 3개 (잠의 과학 · 도시 열섬 현상 · 미루기의 심리학), 문장별 해석과 구문 분석 포함
- `content.js` — 지문별 핵심 어휘, 문법 문제, 독해 문제, 말하기 질문, 문법 문제 은행
- `app.js` — 앱 동작 전체

## 참고 · 한계
- 발음 점수와 음성 입력은 브라우저의 음성 인식(Web Speech API)을 쓰므로 **Chrome/Edge**에서만 동작합니다.
- AI 대화 튜터는 오프라인에서도 동작하는 규칙 기반입니다. 더 깊은 교정은 "생성형 AI 피드백 프롬프트 복사"로 ChatGPT·Claude·Gemini에 요청할 수 있습니다.
- 문법 자동 탐지는 패턴 기반이라 일부 오탐이 있을 수 있습니다(참고용 표시).
